# PPI Écoles — Direction de l'Éducation, Saint-Denis de La Réunion

Suivi du Plan Pluriannuel d'Investissement des écoles : tableau de bord,
liste des travaux, alertes et cartographie des écoles de la commune.

Les données sont dans Supabase et protégées par des règles d'accès : sans
compte inscrit, ce site n'affiche aucune opération. La clé publique présente
dans `donnees/config.js` est faite pour figurer dans une page web ; elle
n'ouvre que ce que ces règles autorisent.
